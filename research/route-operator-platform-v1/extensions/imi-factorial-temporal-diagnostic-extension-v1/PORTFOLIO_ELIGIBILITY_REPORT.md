# IMI Factorial-Temporal Portfolio Eligibility Report v1

## Determination

The NASA FD001 validation supplied external held-out evidence that condition, direction, and persistence contain materially different predictive information. That result is study-specific evidence, not yet a reusable portfolio instrument.

This package therefore adds a separately versioned successor layer that consumes immutable core receipts and emits a factorial temporal diagnostic:

```text
CURRENT_CONDITION
+
DIRECTION
+
PERSISTENCE
+
BOTTLENECK
```

It does not change the frozen IMI core, the falsification extension, or any archived result.

## Portfolio classification

| Study | Current eligibility | Disposition |
|---|---|---|
| NASA C-MAPSS FD001 | Temporal architecture already applied | Preserve as empirical reference |
| Agricultural colony resilience | Full retrospective temporal reanalysis eligible | First lawful successor reanalysis candidate |
| Hospital general information | Snapshot only | Requires aligned later release |
| Hospital measure-level robustness | Snapshot only | Requires multiperiod facility data |
| Spontaneous speech | Snapshot only | Requires repeat participant observations |
| DSSI sovereign debt schedule | Exact identity unresolved; one schedule is not longitudinal | Bind exact package and assemble multiple country-years |

## Scientific boundary

A new output language can be produced for every study, but materially new temporal findings require repeated comparable observations. Missing direction and persistence are not imputed.

The agricultural successor, if separately authorized after this extension is admitted, must remain retrospective and exploratory because the existing outcomes have already been inspected.

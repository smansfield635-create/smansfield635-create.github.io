# 1. Purpose

The protected Research Frontier product shell is the orbital carousel. The newer Publication Crosswalk v3 candidate defines seven public research objects and a three-plane public model:

- `MEANING`
- `EVIDENCE`
- one global `SHARED_BRIDGE`

The old preservation contract still freezes six carousel objects. This amendment resolves that future cardinality mismatch **without reopening the product architecture**.

The controlling proposition is:

> **Change the count, not the interaction identity. Bind the seven v3 objects into the protected carousel, preserve two primary sides per card, and preserve one shared contextual Bridge.**

This amendment is intentionally narrower than a page-construction specification.

# 9. Three-plane publication model

Each of the seven orbit objects has two primary card sides:

1. `MEANING`
2. `EVIDENCE`

Either primary side may open one global contextual plane:

3. `SHARED_BRIDGE`

The Shared Bridge is not a third card side in the scientific/evidentiary sense. It is one shared contextual inspection plane.

Therefore the public experience contains:

`7 cards × 2 primary sides + 1 shared contextual bridge`

not:

`7 cards × 3 independent scientific sides`

and not:

`8 orbit cards`.

# 13. Shared Bridge contract

There is exactly one global Shared Bridge.

Primary practical proposition:

> **THE CONSTRAINT IS SHARED. THE EVIDENCE IS NOT.**

Lead question:

> **What does this situation actually allow next?**

The Bridge begins in practical language. It may then expose the bounded constraint-centered spine:

`OBSERVATION -> CONSTRAINT -> ADMISSIBLE MOVEMENT -> BOUNDARY -> RELATIONAL STRUCTURE -> EXECUTION`

That spine remains lineage/synthesis context, not a universal validated theory.

The Bridge may use the selected card's exact v3 `bridgeRelation` to contextualize why that card connects to the shared question.

The Bridge may not:

- become an eighth orbit card;
- become a third independent evidence side;
- replace Evidence;
- imply that one program validates another;
- merge scientific, operational-control, and claim-entitlement result classes;
- upgrade the cross-program synthesis hypothesis into a universal theory.

`BRIDGE_CONTEXTUALIZES_RELATION; IT_DOES_NOT_TRANSFER_EVIDENCE`

# 16. Required transitions

## Orbit selection

`ORBIT(i) + horizontal drag/swipe -> ORBIT(j)`

`ORBIT(i) + Left/Right -> ORBIT(j)`

where `i,j` are valid seven-card identities.

## Open

`ORBIT(i) + open selected -> CARD_OPEN_MEANING(i)`

unless a separately governed retained-state rule explicitly restores `CARD_OPEN_EVIDENCE(i)`.

## Side change

`CARD_OPEN_MEANING(i) + horizontal side gesture/control -> CARD_OPEN_EVIDENCE(i)`

`CARD_OPEN_EVIDENCE(i) + horizontal side gesture/control -> CARD_OPEN_MEANING(i)`

## Vertical reading

`CARD_OPEN_MEANING(i) + vertical gesture -> CARD_OPEN_MEANING(i) / scroll`

`CARD_OPEN_EVIDENCE(i) + vertical gesture -> CARD_OPEN_EVIDENCE(i) / scroll`

## Lens

`CARD_OPEN_EVIDENCE(i) + open applicable lens(k) -> EVIDENCE_LENS(i,k)`

`EVIDENCE_LENS(i,k) + close -> CARD_OPEN_EVIDENCE(i)`

## Bridge

`CARD_OPEN_MEANING(i) + Inspect Shared Bridge -> SHARED_BRIDGE(i,meaning)`

`CARD_OPEN_EVIDENCE(i) + Inspect Shared Bridge -> SHARED_BRIDGE(i,evidence)`

`SHARED_BRIDGE(i,s) + Return to Selected Side -> CARD_OPEN_s(i)`

## Return to orbit

`CARD_OPEN_MEANING(i) + Return to Orbit -> ORBIT(i)`

`CARD_OPEN_EVIDENCE(i) + Return to Orbit -> ORBIT(i)`

No return transition may default to card 1 merely because the inspected overlay/card closes.

# 18. Gesture arbitration

Gesture intent must be resolved before transition commitment.

## 18.1 Orbit

- horizontal drag/swipe rotates/selects among seven cards;
- vertical gesture remains normal page behavior;
- a completed horizontal drag must not accidentally trigger card opening;
- orbit interaction remains the foreground gesture authority.

## 18.2 Open card

- horizontal intent changes Meaning/Evidence;
- vertical intent scrolls current side;
- background orbit is suspended/inert for card interaction;
- a side transition must not rotate the orbit beneath the card.

## 18.3 Evidence lens

- vertical reading remains inside the active technical surface;
- lens controls do not leak gesture authority to the orbit;
- closing the lens restores Evidence without changing selected card.

## 18.4 Shared Bridge

- vertical reading remains Bridge reading;
- no background orbit rotation;
- no accidental Meaning/Evidence side change;
- Bridge close restores the saved `returnSide`.

Directional locking must use a deliberate threshold/axis-decision rule or equivalent behavior so a diagonal vertical read does not unexpectedly become a horizontal navigation command.

## Navigation grammar

The shell must keep these operations distinct:

- `FOCUS` — move attention in the current field.
- `INSPECT` — expose bounded authorized information while preserving orientation.
- `FOLLOW` — traverse an explicitly declared scientific relation.
- `ENTER` — descend into authorized containment/depth.

`FOCUS != INSPECT != FOLLOW != ENTER`

Spatial adjacency, scale, distance, order, orbital placement, or animation may not create scientific meaning.

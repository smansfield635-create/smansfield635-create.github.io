    Story focus. This story layer narrows Constraints around one explicit distinction: capacity defines what can be carried.

    Engineering

    Lens frame. Constraints map to resource budgets, validation rules, saturation points, error budgets, admission criteria, guard clauses, and tradeoff analysis.

    What this selection adds. Treat capacity as a distinct control point inside Constraints. Give it an owner, explicit state, transition rule, and failure output so the implementation cannot hide it inside a general label.

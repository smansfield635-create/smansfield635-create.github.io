# F6 — Depth and Inquiry

Program: `METHODS_MODELS_INTEGRATED_ENVIRONMENT_CONSTRUCTION_v1`
Gate: `F6_DEPTH_AND_INQUIRY`

F6 defines how a user may interrogate an already-authorized scientific object at progressively greater explanatory depth without changing the scientific object, its canonical state, its evidence standing, its claim ceiling, its custody, its execution standing, or its semantic relations.

Canonical depth sequence:

`D0 ORIENTATION -> D1 MEANING -> D2 STRUCTURE -> D3 EVIDENCE -> D4 PROVENANCE`

Governing law:

`DEPTH_CHANGES_RESOLUTION_OF_EXPLANATION_NOT_AUTHORITY_OF_THE_SCIENCE`

Structural boundary:

- `DEPTH` is not a fourteenth F2 state axis.
- Depth does not mutate `LENS` or `VIEW_MODE`.
- Depth is an inquiry-envelope parameter outside the canonical F2/F3 state.
- Every depth projection of one object must bind the same F3 canonical-state digest.
- Disclosure is cumulative. Deeper levels may add authorized information but may not replace, reinterpret, or suppress already-required qualifiers.
- Material qualifiers must appear at or before the first depth where omitting them could change the user's conclusion.
- Direct entry at any depth must remain scientifically valid without prior narrative traversal.

F6 does not authorize public page mutation, visual construction, spatial topology, geometry, accessibility implementation, or F7+ work.

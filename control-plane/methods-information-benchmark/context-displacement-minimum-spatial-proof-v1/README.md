# Methods Context Displacement Engine — Minimum Spatial Proof v1

Status: nonpublic experience proof. No public page mutation. No merge authority.

This artifact tests whether Methods and Models can be experienced as a spatially navigable knowledge environment rather than a page of cards and modals.

## Exact scope

- Two Euclidean stages.
- Three ordered model objects per stage.
- One fully populated object: Pressure-to-Capacity Ratio.
- Three permanent expressions: Practical, Engineering, Evidence / empirical.
- Inter-stage displacement, intra-stage displacement, focus, lens rotation, and exact return.
- Pointer, touch, keyboard, reduced-motion, and linear-document equivalents.

- Governing construction base: `0d88fe21aba99c97b73fcdc68d44af57d55b68be`
- Information and state source: `2044e7ab5d27af7bcfbd477a6c3ee046549744ed`

## Interaction sequence

1. Observe the current stage and the distant stage.
2. Travel between stages without document scrolling.
3. Move among three ordered model objects.
4. Focus the centered model so it moves forward in depth.
5. Rotate the same model through Practical, Engineering, and Evidence / empirical expressions.
6. Return and verify restoration of the prefocus stage, object, lens, and view state.

## Keyboard

- `Shift + Left/Right`: stage travel
- `Left/Right`: model movement
- `Enter`: focus centered model
- `1`, `2`, `3`: lens expression
- `Escape`: exact return

## Boundaries

This proof does not authorize full Methods integration, additional stages, public deployment, named-award claims, PR #613 merge, permanent visual-instrument freeze, or H-Earth terrain/runtime inheritance.

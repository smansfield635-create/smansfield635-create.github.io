What this build is

Public Talk v2 keeps language-model inference on your device and adds a bounded evidence route for questions that require current public information. Search returns candidate evidence to the local model; search rank is not treated as truth. It does not claim frontier-model capability or professional authority. Governed private Execution remains separate and is not exposed by this public chat.

WebLLM 0.2.85 is the primary browser-local backend. If it cannot initialize, wllama 3.6.0 can attempt a CPU/WASM fallback using the same Qwen2.5 0.5B model family. For a freshness-triggered request, a bounded query may leave the browser to retrieve current public source candidates; the conversation itself is not sent to a hosted model API. Diagnostic reports omit prompt and conversation content.

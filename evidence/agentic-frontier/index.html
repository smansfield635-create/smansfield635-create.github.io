Scientific Frontier · Object 01 · Equal face 01

Do viable futures reveal fragility?

The falsifiable proposition is that information in the geometry of a system’s remaining viable transitions may add predictive information beyond a description of its present state alone.

Scientific evidence boundary: prospective testing and replication are being extended. Broad cross-domain generality, independent replication, and a universal law are not claimed.

A claim designed to be broken

The proposition predicts that viable-transition geometry can add information beyond a present-state description. A useful test must make it possible for that added signal to disappear.

Freeze first

Define the exact claim, benchmark, comparator, and stopping conditions before outcomes can steer the procedure.

Keep contradictions

Negative, null, and contradictory results belong in the record beside successful findings.

Scroll vertically to read this face. Use its tabs for evidence detail; use the perspective control or a horizontal swipe to turn the object over.

Try to falsify it

Preserve the predeclared evaluation boundary and ask whether the apparent signal disappears under a stronger comparator, a clean implementation, or a genuinely untouched benchmark.

What would count as progress

Independent reproduction, stronger matched controls, clean-room implementation agreement, or a clear falsification that explains the existing observations.

What would not

Retuning the procedure after seeing the outcome or quietly removing contradictions from the record.

The strongest attack is part of the research object, not an appendix to it.

Agentic Frontier · Object 04 · Equal face 02

Can the procedure survive its author?

Implementation independence, exact-state recovery, and explicit succession make it possible to test whether a procedure can be repeated without relying on one operator’s memory.

Agentic evidence boundary: the architecture exposes independence and succession constraints. It does not establish that every implementation is independent or every recovery is complete.

Separate hypothesis from evaluation

Frozen protocols, untouched tests, and clean implementations strengthen the boundary between forming a claim and judging its outcome.

Exact starting state

A reproducer should know which governing head, task, model, runtime, comparator, and verifier condition were used.

Independent implementation

Where independence matters, the implementation should not inherit hidden decisions from the result it is meant to test.

The procedure should be inspectable enough to be challenged outside its original execution context.

1Recover the last durable exact state.
2Identify terminal and incomplete work without rewriting it.
3Admit a bounded successor under current authority.
4Requalify the successor as a new exact candidate.

Succession preserves the trail; it does not inherit qualification automatically.

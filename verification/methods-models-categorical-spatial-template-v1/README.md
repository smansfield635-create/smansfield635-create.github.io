# Methods Models Categorical Spatial Template Vertical Slice v1

This nonproduct vertical slice makes the existing Methods categorical state operational as a deterministic three-dimensional field.

It does not create a new Methods taxonomy. `catalog-source.mjs` extracts the canonical `families` literal from `laws/research/methods-and-models/showroom.js`; `descriptor-registry.mjs` projects those native identities into stable family planes, model positions, lens relations, neighbor references, and camera anchors.

Authority remains separated:

- Native Methods owns family, model, lens, display, and inspection semantic state.
- The spatial descriptor registry owns categorical-to-spatial projection.
- The renderer owns camera, visible cluster, detail budgets, animation, and immutable perceptual-return snapshots.
- H-Earth source coupling is absent. Only general controller, compositor, lifecycle, and receipt patterns are reimplemented.
- The observer records pre-acceptance execution. It does not declare beauty or product acceptance.

The expression slots are deliberately nonblocking. Landmark identity is unresolved; material and atmosphere use neutral structural profiles.

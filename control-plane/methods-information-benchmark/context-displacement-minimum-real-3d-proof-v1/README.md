# Methods Context Displacement — Minimum Real 3D Proof v1

Status: nonpublic construction candidate. No public page mutation. No deployment or merge authority.

This proof tests whether Methods and Models can be handled as a direct-manipulation spatial instrument rather than a card deck, modal sequence, or vertically scrolled engineering page.

## Visitor sequence

1. Sweep the field directly.
2. Settle a model into the active position.
3. Tap or press Enter to approach the selected model in real depth.
4. Read Practical, Engineering, and Evidence simultaneously as three expressions of the same model.
5. Rotate expression emphasis without replacing the model identity.
6. Return to the exact prefocus state through the 13-field SHA-256 snapshot contract.
7. Travel between the two stages through camera displacement rather than document replacement.

## Primary interaction grammar

- One pointer/finger: orbit and sweep among models.
- Flick: bounded directional settlement.
- Tap: focus the settled model.
- Two pointers/fingers: spatial stage travel.
- Pinch or wheel: inspection distance.
- Escape or Return: exact restoration.
- 1 / 2 / 3: change lens emphasis while all three lenses remain visible.
- Keyboard arrows: secondary equivalent, not the primary visual product.

# M1R2 — Method Procedure Field

`M1R2_METHOD_PROCEDURE_FIELD` is the second bounded manifestation revision after M1R1 closed mobile topology fragmentation but failed dependency-direction legibility.

It preserves the exact M1R1 semantic population: `METHODS`, fifteen source-bound method stages, and the sixteen dependencies derived from `sequence[].requires[]`. It does not add, delete, reverse, reinterpret, or infer scientific relations.

The revision is deliberately narrow:

- each declared dependency still renders source → target;
- each path now terminates outside the target-card boundary so its arrowhead is perceptually exposed rather than occluded beneath the target card;
- selected incoming/outgoing relation emphasis is preserved;
- the successful narrow whole-topology reflow is preserved unchanged;
- human-readable relation and custody presentation is preserved.

Responsive positions remain nonsemantic. Stage number remains the explicit source-bound order cue. Public Methods files are outside this candidate.

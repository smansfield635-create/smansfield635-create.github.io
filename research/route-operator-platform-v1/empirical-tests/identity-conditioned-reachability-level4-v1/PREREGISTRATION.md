# Preregistered adversarial disposition

## Governing question

Can the bounded target system continue producing the same visible output while the original identity-defining verification relation is absent, and can controlled interventions distinguish endogenous preservation, external support, substitution, fracture, restoration, and hysteretic reentry?

## Success condition

All nine frozen predictions must pass, the three matched-output conditions must remain distinguishable by provenance and future response, and the independent reproducer must reproduce every claim-scoped condition disposition.

## Failure condition

A single clean failure of a core prediction is retained as an adverse result. In particular, the candidate loses this engineered test if unrelated capacity reopens the original route, a substitute passes the original-only challenge, support withdrawal does not expose the missing internal route, or relation-specific restoration does not reopen it.

## Ambiguous condition

Execution or custody failure produces `INVALID` or `UNEVALUABLE`, not scientific support or falsification.

## No rescue rule

No prediction, threshold, system boundary, identity criterion, route definition, or implementation may be changed after the first execution while retaining version `1.0.0`.

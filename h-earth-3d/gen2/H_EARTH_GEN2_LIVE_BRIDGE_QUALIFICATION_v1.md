PUBLIC ROUTE: /showroom/globe/h-earth/

## Purpose
Prove whether demonstrated Gen-2 terrain technology can materially alter the actual H-Earth public route while preserving the live page, camera, controls, coastline/world identity and interaction behavior.

## Frozen
Production remains untouched. This branch is exact-SHA inspection only.

## Allowed mutation
Terrain visual representation only.

## Gen-2 retained technology
- canonical terrain-field consumption
- higher-density terrain geometry
- recomputed geometric normals
- PBR-capable terrain lighting/material path

## Explicitly discarded
- random tree population
- random boulder population
- fabricated cavern proxy/arch
- standalone Gen-2 beach dressing
- standalone Gen-2 camera/world shell

## Qualification
A bridge candidate must prove:
1. parent is the frozen live H-Earth authority;
2. actual public route executes;
3. Gen-2 terrain representation is present and visibly drawn;
4. prior terrain visual does not mask/double-render it;
5. existing public camera/controls remain functional;
6. no production deployment occurs.

## Decision
A: visible improvement → freeze bridge architecture.
B: visible change without improvement → renderer development continues on real route.
C: bridge cannot materially alter real route without breakage → terminate Gen-2 migration path.

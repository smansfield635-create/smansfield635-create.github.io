# ARCHCOIN Compass Calibration Workspace

## Status

- Calibration and extraction workspace only.
- No live compass authority.
- No production deployment authority.
- No automatic inheritance into ARCHCOIN.
- No claim that any extracted feature is canonical until separately admitted.

## Purpose

Use ARCHCOIN as the calibration chamber for developing a reusable compass reference model from the strongest verified parts of the inspected compass implementations.

The workspace keeps four classes of material separate:

1. source evidence — what an inspected file actually implements;
2. extracted capability — the useful mechanism or contract recovered from that source;
3. candidate standard — a proposed reusable compass rule;
4. admitted standard — a rule that has passed compatibility, behavioral, visual, accessibility, and preservation review.

## Calibration categories

- world and geometry authority;
- camera and compositor authority;
- controller and transaction authority;
- pointer and gesture behavior;
- orbital and cluster motion;
- primary-target custody;
- navigation and return behavior;
- label and semantic-control behavior;
- visual scale and readability;
- responsive and accessibility behavior;
- initialization, receipts, validation, disposal, and failure handling.

## Admission rule

A feature may enter the reusable model only when:

- its source path and source identity are recorded;
- its actual behavior is inspected rather than inferred from naming;
- its ownership boundary is explicit;
- its dependencies are known;
- it does not duplicate or contradict a stronger admitted mechanism;
- its extraction can be expressed without importing page-specific identity;
- its test and failure requirements are stated;
- its use in ARCHCOIN remains separately authorized.

## Planned workspace artifacts

- `source-registry.js` — inspected source families and evidence status;
- `extraction-ledger.js` — capability candidates and admission state;
- `reference-model.contract.js` — future reusable compass authority contract;
- `compatibility-matrix.js` — cross-compass dependency and conflict analysis;
- `test-corridor.js` — behavioral and structural tests;
- `adapters/` — page-specific adapters created only after the reference model stabilizes.

## Current boundary

This workspace does not replace the seven-file ARCHCOIN construction package. It is an upstream calibration and extraction lane. The seven-file package may consume admitted results later through explicit authorization.

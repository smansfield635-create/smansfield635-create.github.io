## Purpose

F3 operationalizes the F2 13-axis canonical environment-state kernel without changing its ontology. It defines universal resolution semantics, explicit default admission, cross-axis and transition validity, failure precedence, deterministic canonicalization, and deterministic serialization/restoration.

F3 does not bind research objects, evidence datasets, models, equations, case-specific rules, URLs, navigation runtime, visual layout, spatial topology, geometry, or public Methods behavior.

## Governing rule

`RESOLUTION_MAY_DETERMINE_STATE_VALIDITY_BUT_MAY_NOT_REDEFINE_STATE_MEANING`

The per-axis statuses remain exact and non-interchangeable:

- `DECLARED`
- `UNSET`
- `UNEVALUABLE`
- `NOT_APPLICABLE`

State-level resolution classes are separate metadata:

`INVALID > UNEVALUABLE > PARTIAL > RESOLVED`

That precedence never rewrites an axis status.

## Default law

F3 ships with no substantive defaults. A default may be applied only when all of the following are true:

1. the target axis is exactly `UNSET`;
2. the default is explicitly registered;
3. the registration names the axis and its F2 mutation-authority class;
4. the registration supplies nonempty authority and source references;
5. the declared value conforms to the frozen F2 axis shape.

Defaults are forbidden for `UNEVALUABLE` and `NOT_APPLICABLE`. F3 may not infer a scientific value from interface state, route state, content position, or research-specific data.

## Universal validity law

Static validity is structural and ontology-level only. Research-specific admissibility belongs to F4 or later.

Transition validity is plane-aware. Representation, navigation, and content-binding transitions may not mutate scientific state. Scientific transitions must name a mutation kind whose allowed axes are frozen in this package.

## Canonical serialization

Canonical serialization preserves the F2 axis order and all array order. Object keys are emitted deterministically. Canonicalization may normalize representation order only; it may not change values, status, authority references, source references, route order, or claim-prohibition order.

## Advancement boundary

A passing F3 authorizes construction of F4 only. It does not start F4 and creates no public mutation, scientific claim upgrade, content binding, visual construction, topology, or geometry authority.

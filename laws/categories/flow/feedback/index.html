Engineering controls

Failure behavior

A later change cannot be called feedback unless the return path and resulting state change are observed or otherwise established.

Practical reading

Show how an outcome changes a later action, setting, allocation, or behavior.

Engineering reading

Empirical reading

Show whether a return signal and subsequent state change were actually observed, rather than inferred from sequence alone.

Method

Separate output, observation, response, and revised input so the claimed loop can be challenged at each link.

Audit boundary

Temporal ordering is necessary but insufficient. The record must identify a return path and a change attributable to that return before Feedback is established.

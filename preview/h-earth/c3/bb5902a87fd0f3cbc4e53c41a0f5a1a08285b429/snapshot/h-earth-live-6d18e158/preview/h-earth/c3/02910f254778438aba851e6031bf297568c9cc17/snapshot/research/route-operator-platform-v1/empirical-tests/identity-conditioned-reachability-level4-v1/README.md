# Identity-Conditioned Reachability Level 4 Gauntlet v1

This package freezes and executes the first controlled constitutive-relation disruption and restoration experiment for the identity-conditioned reachability candidate.

## Scientific object

The experiment distinguishes visible output continuity from continued operation through the original bounded internal relation. It deliberately creates matched-output states produced by:

- the original internal route;
- external support;
- a functionally equivalent substitute.

It then tests support withdrawal, unrelated compensation, relation-specific restoration, an original-lineage held-out challenge, and hysteretic reentry.

## Authority boundary

This is an engineered deterministic Level 4 proof-of-concept. It tests controlled causal route manipulation and matched-output identity discrimination inside one explicitly bounded software system.

It does not establish natural-system validity, independent recovery of constitutive relations, cross-domain invariance, or a universal scientific law. It does not modify the frozen IMI core or any archived empirical result.

## Frozen execution

The frozen files must be committed before the first execution. Execution results are additive under `executions/` and may not modify the frozen contract, system, predictions, alternatives, failure ownership, or implementation.

Run from this directory:

```bash
python verify_level4_gauntlet_v1.py
python level4_gauntlet_v1.py --output executions/run-001/execution-receipt.json
python independent_reproducer_v1.py executions/run-001/execution-receipt.json
```

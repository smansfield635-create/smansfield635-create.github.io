# F9 Integrated Environment Assembly

This package composes the terminal F1-F8 authorities into one nonpublic text-first stateful Methods & Models environment. Integration is composition, not redefinition: F9 may consume existing scientific state, content, navigation, depth, interaction, accessibility, and spatial-semantic authorities but may not create scientific meaning, claim strength, cross-object relations, or new controls.

The integrated object has two distinct planes. The global semantic plane exposes the complete governed portfolio and typed relation/projection graph. The stateful operational plane exposes only registered Level-A entry objects through the inherited F5-F7 authority chain. Portfolio visibility does not create stateful entry authority.

No public Methods/Laws page, PR #541 source, F10 artifact, or final visual implementation is created here.

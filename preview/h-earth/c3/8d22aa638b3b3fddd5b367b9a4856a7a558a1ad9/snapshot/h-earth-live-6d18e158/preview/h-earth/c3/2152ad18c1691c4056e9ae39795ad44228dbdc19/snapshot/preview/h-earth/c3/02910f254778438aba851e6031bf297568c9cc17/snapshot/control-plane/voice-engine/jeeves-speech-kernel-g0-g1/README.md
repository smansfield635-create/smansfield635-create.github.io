# Diamond Gate Speech Kernel — Jeeves G0/G1

Status: CONSTRUCTED_PENDING_LISTENING_QUALIFICATION

This package freezes the first reproducible Diamond Gate speech baseline and its timing-only successor.

Important provenance note: the earlier ephemeral robotic Compass synthesizer source was not persisted in the repository and could not be recovered from the file library. Therefore G0 is the first canonical reproducible baseline, reconstructed from the documented deterministic pipeline; it must not be described as byte-identical to the earlier ephemeral render.

## Generation law

G0 is immutable after this package is admitted. G1 may change only phoneme duration, word gaps, punctuation pauses, and sentence/boundary timing. Pitch, energy, excitation, formants, spectral behavior, and waveform generation are identical between G0 and G1.

The same eight Compass lines are rendered in both generations.

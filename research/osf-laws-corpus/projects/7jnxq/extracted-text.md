Methods Appendix: Diagnostic Framework
Study Type
This work uses a non-experimental, diagnostic classification methodology. No interventions,
treatments, or subject assignments are performed.
Evidence Selection
Only externally observable, publicly documented evidence is admissible. Subjective interpretation and
inferred intent are excluded.
Evidence Window

comparison.
Application Procedure
Predefined diagnostic rules are applied uniformly without tuning or weighting.
Reproducibility

Diagnostic Protocol / Rulebook
Purpose
This document fixes the diagnostic rules used to evaluate coherence, fragmentation, and trajectory. No
weighting, tuning, or post-hoc adjustment is permitted after preregistration.
Admissible Evidence
Only externally observable, publicly documented evidence is admissible. Examples include declared
constraints (laws, policies, rules), recorded outcomes, enforcement or corrective actions, rule changes,
and documented institutional responses. Inferred intent, psychology, or moral judgment are excluded.
Diagnostic Set
1) Constraint Alignment Diagnostic (C.A.D.): assesses correspondence between declared constraints
and realized outcomes.
2) Constraint Transparency Diagnostic (C.T.D.): assesses interpretability and clarity of constraints.
3) Constraint Fragmentation Diagnostic (C.F.D.): assesses persistent divergence among constraints,
behaviors, and outcomes.
4) Internal Misalignment Diagnostic (I.M.D.): assesses coherence within individual or sub-unit decision
structures.
5) Trajectory Diagnostic (T.D.): assesses direction of system evolution across successive evidence
windows.
Classification Rules
Coherence-Preserving: sustained alignment with stable or decreasing corrective load.
Marginally Stable: alignment maintained only through increasing enforcement or rule complexity.
Dissipative: persistent fragmentation with escalating corrective load and degrading outcomes.
Falsifiability
The framework is falsified if independent observers applying these rules to the same admissible
evidence do not converge on the same classification, or if sustained coherence is observed despite
persistent fragmentation.

```

Case Selection & Evidence Window Specification
Inclusion Criteria
Cases must be publicly documented systems or events with sufficient admissible evidence to apply all
diagnostics. Documentation must allow identification of declared constraints, observed outcomes, and
corrective actions.
Exclusion Criteria
Cases lacking verifiable records, relying primarily on subjective accounts, or requiring inference of
intent are excluded.
Evidence Windows
Each case is evaluated within a fixed temporal or event-based evidence window defined prior to
analysis. Mixing evidence across windows invalidates comparison.
Boundary Handling
If evidence spans multiple periods, separate windows are defined and evaluated independently. No
retroactive window adjustment is permitted after analysis begins.

Observer Replication Guide
Objective
Enable independent observers to reproduce classifications using the same rules and admissible
evidence.
Inputs Required
Publicly accessible documents defining constraints, outcomes, and corrective actions for the selected
case; a defined evidence window; and this protocol.
Procedure
1) Verify admissibility of evidence.
2) Apply each diagnostic independently (C.A.D., C.T.D., C.F.D., I.M.D., T.D.).
3) Record classifications without weighting or aggregation.
4) Compare convergence across observers.
Replication Criterion
Replication is achieved when independent observers converge on the same system classification.
Persistent disagreement indicates falsification or rule ambiguity requiring revision in a future version.

```

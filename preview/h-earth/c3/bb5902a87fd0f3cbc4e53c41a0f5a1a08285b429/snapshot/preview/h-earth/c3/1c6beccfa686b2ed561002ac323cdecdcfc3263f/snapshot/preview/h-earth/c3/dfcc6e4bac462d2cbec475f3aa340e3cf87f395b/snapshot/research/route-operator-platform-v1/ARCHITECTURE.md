# Architecture

Release class:

```text
PLATFORM_CORE_WITH_EXTERNAL_FROZEN_IMI_AUTHORITY
```

```text
COMMON_ROUTE_OPERATOR_ENGINE
├── external frozen IMI authority pointer
├── MCCI mathematical-component-continuity scoring kernel
├── GESI graphic-expression-stability scoring kernel
├── THEORY_AND_PERSPECTIVE_REGISTRY
└── EMPIRICAL_RESEARCH_ENGINE
```

For required component values `x_i in [0,1]`:

```text
C = product(x_i)
L = min(x_i)
T = conjunction(explicit_hard_condition_i)
S = 1 - C
```

The engine enforces `INVALID > UNEVALUABLE > NUMERIC` at both snapshot and series levels. Invalid or unevaluable receipts cannot be silently removed to produce a numeric series result.

## Identity-safe empirical chain

A confirmatory theory crosswalk requires all of the following:

```text
OBSERVED_PLATFORM_ID = PLATFORM_ID
OBSERVED_INSTRUMENT_ID = STUDY_INSTRUMENT_ID
OBSERVED_INSTRUMENT_VERSION = STUDY_INSTRUMENT_VERSION
OBSERVED_ROUTE_ID = STUDY_ROUTE_ID
OBSERVED_ROUTE_VERSION = STUDY_ROUTE_VERSION
OBSERVED_RECEIPT_SHA256 = DECLARED_INPUT_RECEIPT_SHA256
DATA_SHA256 = VERIFIED_RECEIPT_SHA256 OR EXPLICIT_POINTER_ONLY
EXECUTED_ANALYSIS_CODE_SHA256 = STUDY_ANALYSIS_CODE_SHA256
THEORY_FROZEN_AT < DATA_LOCKED_AT <= ANALYSIS_STARTED_AT <= ANALYSIS_COMPLETED_AT
```

Any identity, hash, state, analysis-code, timestamp, or comparison-rule failure returns `INVALID`; it does not receive a scientific support or falsification disposition.

## Adapter hard-rule authority

Numeric magnitude never implies hard-pass status. Every native mapping must use one declared rule:

```text
EXPLICIT_NATIVE_BOOLEAN_FIELD
EXPLICIT_PREDECLARED_THRESHOLD
EXPLICIT_HARD_RULE_FUNCTION_ID
NO_HARD_GATE
```

Source tools remain authoritative for native evidence. Adapters are authoritative only for predeclared field and hard-rule mapping. Instruments are authoritative only for their calculations. The empirical engine analyzes compatible frozen outputs but cannot rewrite measurement rules after result access.

## Custody boundary

The complete observer-grade IMI source package remains private Drive authority. This repository contains its exact package identity, location, and approved ZIP SHA-256. The platform CI verifies the pointer record but cannot recompute private ZIP bytes that are not present in the repository.

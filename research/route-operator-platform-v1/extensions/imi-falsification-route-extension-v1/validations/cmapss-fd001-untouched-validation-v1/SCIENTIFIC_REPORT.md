## Decisive result

The factorial temporal IMI model reduced RMSE by 14.78% relative to age-only and by 11.98% relative to condition-only, with paired 95% bootstrap intervals above zero. This supports the value of adding direction and persistence to multidimensional condition.

The multiplicative model did not outperform the additive factorial model. It was 29.10% worse in RMSE, and it was also 14.74% worse than the weakest-factor model. Multiplicative specificity is therefore not supported.

The additive factorial model was the best compressed model (RMSE 22.332). The full sensor ridge model was best overall (RMSE 20.770) and materially outperformed the best compressed model by 7.00%.

## Personal interpretation

The work should not be abandoned wholesale. The external validation shows that the factorial temporal concept contains real predictive information. Further investment should be conditional on redesigning the operator and testing whether a compressed relational or route architecture can close the remaining gap to the full sensor model.

The present multiplicative product should not continue as the presumed canonical operator without new evidence.

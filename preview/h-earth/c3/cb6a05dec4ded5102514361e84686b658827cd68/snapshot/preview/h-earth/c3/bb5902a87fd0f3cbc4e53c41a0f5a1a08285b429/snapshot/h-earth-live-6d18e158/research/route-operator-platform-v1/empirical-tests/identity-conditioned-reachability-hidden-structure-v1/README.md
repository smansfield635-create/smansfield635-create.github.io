# Identity-Conditioned Reachability Observer-Blinded Hidden-Structure Gauntlet v1

This package is a computationally observer-blinded successor to the first engineered Level 4 gauntlet.

The hidden system contains an opaque relation catalog, a concealed constitutive path, decoy relations, an external-support route, a functional substitute, unrelated capacity, and a fracture latch with reentry clearance. The observer receives only the public relation catalog, generated black-box training observations, and the intervention definitions for held-out cases; held-out outcomes remain concealed. The observer process is executed in an isolated temporary directory that does not contain the hidden system implementation or hidden truth.

The package tests whether a frozen observer can recover the constitutive relation set, derive the bounded system boundary, reconstruct the original route, and predict withheld support, substitution, noncompensation, and hysteretic-reentry outcomes.

Scientific boundary: this is an engineered computational blinding pilot. It does not constitute independent human observer recovery, natural-system validation, cross-domain invariance, or proof of a universal law.

# Stage 1 inspection notes

Inspect only the Compass instrument behavior in this pass.

1. Drag left and right. The constellation must move and settle on one cardinal.
2. Confirm only the foreground cardinal label is highlighted and that the label changes as the foreground changes.
3. Open each cardinal. Its room cluster must appear without changing the other cardinal data.
4. Rotate a room cluster. The highlighted room label must follow the foreground room.
5. Select a foreground room. No navigation should occur yet.
6. Use Return to Orbit. The four-cardinal constellation must return cleanly.
7. Confirm the instruction band changes between constellation, cluster, and selected-room states.
8. Test keyboard Left/Right, Enter/Space, and Escape.

Any failure in these behaviors blocks Stage 2.

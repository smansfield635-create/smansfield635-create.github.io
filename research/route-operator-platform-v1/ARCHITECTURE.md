# Architecture

```text
COMMON_ROUTE_OPERATOR_ENGINE
├── IMI identity and frozen-package reference
├── MCCI mathematical-component continuity
├── GESI graphic-expression stability
├── THEORY_AND_PERSPECTIVE_REGISTRY
└── EMPIRICAL_RESEARCH_ENGINE
```

For required component values `x_i in [0,1]`:

```text
C = product(x_i)
L = min(x_i)
T = conjunction(hard_condition_i)
S = 1 - C
```

The engine enforces `INVALID > UNEVALUABLE > NUMERIC`, nonempty routes, unique component identities, provenance, version matching, and hashed receipts.

Confirmatory priority requires:

```text
THEORY_FROZEN_AT < DATA_LOCKED_AT < ANALYSIS
```

Retrospective interpretations are preserved but cannot be represented as prospective predictions.

Source tools remain authoritative for native evidence. Adapters are authoritative only for predeclared field mapping. Instruments are authoritative only for their calculations. The empirical engine analyzes outputs but cannot rewrite frozen measurement rules after result access.

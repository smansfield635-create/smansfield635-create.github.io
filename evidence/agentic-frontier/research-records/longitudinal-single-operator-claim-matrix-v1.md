# Agentic Frontier Longitudinal Claim Matrix v1

Date: 2026-09-29
Status: bounded research synthesis
Scope: Diamond Gate Bridge longitudinal production record plus frozen Agentic Frontier comparative study.

## Claim matrix

### PROVEN / REPOSITORY-BOUNDED

1. The repository contains a longitudinal transition in operating architecture rather than only a change in commit volume.
   - Multi-file AI delegation predates the formal control-plane era.
   - PASS_CLOSED records become systematic in late July 2026.
   - Exact-candidate admission machinery is present from 2026-08-04.
   - Qualification, recovery, publication verification, evidence receipts, routing, and governance become recurring production machinery through August and September.

2. The frozen Agentic Frontier full24 experiment produced a configuration-bounded paired difference.
   - Frozen population: 24 tasks.
   - Diamond Gate tested configuration: 10 PASS.
   - OpenHands 1.14.0 + qwen2.5-coder:7b tested configuration: 0 PASS.
   - Authorized interpretation: a configuration-bounded difference in conversion from agentic intent to verified repository state change.
   - This does NOT establish universal framework superiority or architecture-only causation.

3. Human leverage is mechanically measurable prospectively.
   - DGB Productivity Receipt accepts an explicit substantive-human-intervention count.
   - When supplied, the receipt reports meaningful activities/intervention and publication-closure signals/intervention.
   - Missing historical intervention evidence remains UNKNOWN rather than inferred.

4. A bounded contemporary operation demonstrates joinability of human and repository evidence.
   - PR #5406: 6 candidate commits, 5 authorized files, failed qualification, diagnosed runner repair, successful exact-head qualification, and terminal merge.
   - The corresponding conversation preserves substantive human directives, allowing a bounded human-to-machine operation reconstruction.
   - This specimen demonstrates measurement feasibility; it is not a population estimate.

## BOUNDED / SUPPORTED BUT NOT PRECISELY QUANTIFIED

5. The human role moved upward in abstraction over the project history.
   Evidence supports movement from direct/multi-file delegation toward intent, constraints, authority, exception handling, qualification disposition, and terminal acceptance while deeper machine-side chains execute beneath those decisions.
   Exact historical leverage multiplication is not recoverable uniformly because human-intervention evidence is incomplete for some periods.

6. The project is relevant to the agentic-software frontier as a naturalistic longitudinal case.
   Its research value is the combination of persistent repository history, evolving orchestration/governance machinery, production outcomes, failures/recovery, qualification evidence, and partial human-instruction history.

## EXTERNAL PRECEDENT — NOVELTY CEILING

The following are NOT unique to Diamond Gate Bridge:
- human planning with agent execution;
- multiple agent actions per human prompt;
- autonomous coding-agent pull requests;
- longitudinal repository studies of agent adoption;
- control-plane/orchestrator patterns for coding agents;
- automated tests/guardrails around agents;
- controlled longitudinal studies of agent scaffolding.

Documented 2026 precedents include:
- Anthropic: ~400,000 Claude Code sessions; expert sessions trigger longer action chains per prompt and humans retain more planning while Claude performs more execution.
- OpenAI Symphony: project-management board used as a control plane for continuously running coding agents with automated tests/guardrails and human review.
- METR: task-completion time horizons for frontier agents on software tasks.
- MSR/AIDev studies: large-scale longitudinal analyses of autonomous-agent PR activity, velocity, quality, survival, churn, and lifecycle behavior.
- Ben Sghaier et al.: controlled longitudinal study of 35 sequential coding-agent scaffolding releases.

## CANDIDATE DISTINCTIVE CONTRIBUTION

No source located in the 2026 precedent review was identified as directly matching the complete combination below:
- one primary human operator;
- one persistent production repository;
- months of pre-transition and post-transition history;
- evolution of the agentic scaffolding/control plane itself;
- human instruction traces joinable to repository operations;
- admission, qualification, fail-closed closure, recovery, evidence, and publication governance;
- measured production history;
- and a separate frozen paired agent experiment.

This is an absence-of-located-precedent statement, NOT a claim of world-first status.

## UNRESOLVED

1. Exact historical human-leverage multiplier across January-September 2026.
2. Population-level distribution of machine stages per substantive human intervention.
3. Causal attribution of productivity changes to any single architecture component.
4. Universal comparison against frontier commercial coding agents/configurations.
5. World-first or world-record status.

## Current defensible research statement

Diamond Gate Bridge provides a longitudinal single-operator case study of an AI-assisted development practice evolving into a persistent governed agentic software-production system. The record combines real production history with increasingly formal admission, qualification, recovery, evidence, and publication controls. A separate frozen 24-task paired experiment provides configuration-bounded comparative evidence. The combined record supports study of production scale, delegation depth, operational maturity, and human supervisory burden, but does not establish universal framework superiority, a world record, or a precise historical leverage multiplier.

# Externally Sourced Identity-Conditioned Reachability Bridge v1

This package moves the research from internally authored target systems toward outside implementations and outside datasets without pretending that the fully independent adversarial challenge has already occurred.

It contains two bounded evidence layers:

1. **Externally authored software bridge.** Four third-party software implementations are placed under common theory-team-designed interventions. This layer is exploratory and post-hoc because development executions occurred before repository freeze.
2. **Prospective UCI data bridge.** Three third-party industrial datasets are downloaded and analyzed for the first time by the exact-head workflow after the protocol and code are committed.

## Research question

Does a route- and relation-aware representation distinguish hidden loss of original capacity and predict held-out outcomes better than:

- visible-output continuity treated as identity continuity;
- additive-capacity compensation;
- output-history models;
- unrestricted black-box models?

## Scientific boundary

The software systems and data were not authored by the theory team. The interventions, feature partitions, models, and scoring code were authored by the theory team. This package is therefore an externally sourced bridge, not an independent replication, natural-system validation, or proof of a universal law.

## Frozen UCI decision rule

The prospective data bridge is classified as:

- `BRIDGE_SURVIVES_EXTERNAL_DATA_TEST` when the route-relational model beats the output-history model on at least two of three systems and remains within 5% of the full black-box model on at least two of three systems;
- `BRIDGE_REDUNDANT_OR_INFERIOR` when it beats output history on none of the systems;
- `BRIDGE_MIXED` otherwise;
- `UNEVALUABLE_DATA_OR_EXECUTION_FAILURE` when the external data or execution cannot be validly completed.

All results are retained.

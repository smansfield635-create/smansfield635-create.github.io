# F4 — Scientific Content Binding

Program: `METHODS_MODELS_INTEGRATED_ENVIRONMENT_CONSTRUCTION_v1`

Gate: `F4_SCIENTIFIC_CONTENT_BINDING`

## Purpose

F4 is the first gate allowed to admit scientific intellectual content into the already-frozen universal Methods & Models architecture.

The governing direction is:

`F1 BASELINE -> F2 CANONICAL STATE -> F3 RESOLUTION/VALIDITY -> F4 CONTENT BINDING`

Scientific content populates the upstream machinery. It does not define or modify that machinery.

## Bound content strata

1. Universal scientific definitions already admitted by the merged Gate-0 normalization package: object classes, method sequence, model identities, comparator roles, bounded equations, and evidence/execution separations.
2. Current evidence and claim posture frozen by F1: retained/rejected claims, retrospective standing, prospective execution posture, and explicit claim limits.
3. Empirical instances admitted by CP7: Bio-Lab as the selected bounded retrospective vertical and the QC-corrected hurricane result as adverse bounded Perspective Research context.

## Governing laws

- `CONTENT_BINDING_MAY_INSTANTIATE_EXISTING_STATE_BUT_MAY_NOT_EXPAND_EXISTING_ONTOLOGY`
- `EMPIRICAL_INSTANCE_MAY_DEMONSTRATE_A_METHOD_OR_MODEL_BUT_MAY_NOT_REDEFINE_IT`
- `EXAMPLE_IS_NOT_DEFINITION`
- `CASE_STUDY_IS_NOT_METHOD`
- `OBSERVED_RESULT_IS_NOT_MODEL_DEFINITION`
- `SUPPORTING_RESULT_IS_NOT_VALIDATION`
- `ADVERSE_EVIDENCE_IS_FIRST_CLASS_CONTENT`
- `NEGATIVE_MIXED_INCONCLUSIVE_UNEVALUABLE_AND_ABSENT_CONFIRMATION_STATES_REMAIN_DISTINCT`
- `VISUAL_OR_NARRATIVE_PROMINENCE_MAY_NOT_RAISE_EVIDENTIARY_STRENGTH`
- `NO_CONSTRUCTION_ARTIFACT_MAY_UPGRADE_SCIENTIFIC_STANDING`

## Deliberate non-admission

Research elsewhere in the project is not automatically admitted here. A domain or case requires an exact upstream scientific source identity and bounded claim authority before F4 may bind it. Mere existence in the repository, another room, a draft PR, or project discussion is insufficient.

## Stop boundary

F4 does not implement routing, deep links, page navigation, visual hierarchy, depth controls, accessibility behavior, spatial topology, geometry, integrated assembly, public page mutation, merge, or release. Those remain downstream.

# Laws Compass Page Delivery Prototype

This directory is Workstream A of `LAWS_CHAMBER_GRAPHIC_ENGINEERING_INTEGRATION`.

It is the first real visitor-story slice and is built in conjunction with the engineering laboratory rather than after it.

## Slice 01

`RESEARCH_COMES_F.I.R.S.T._RELATIONSHIP`

The prototype contains:

- the accepted `/laws/` Compass rendered from its unchanged protected runtime in a same-origin isolated frame;
- the real F.I.R.S.T. and Research content relationship;
- the same shared scene mechanic used by the laboratory slice;
- Practical, Engineering, and Empirical lens states;
- Full, Reduced, and Static equivalents;
- phone, tablet, and desktop layout behavior;
- a visible evidence boundary and integration receipt.

The prototype does not copy the Compass renderer, own navigation, alter routes, mutate Laws content, or upgrade evidence.

The top route directory is hidden only inside the isolated frame to evaluate the Compass as the primary navigation object. Production `/laws/` remains unchanged.

# Compass isolated rebuild — Stage 1

This route is an isolated qualification bench. It does not replace `/`, does not import the legacy Compass runtime stack, and does not navigate to estate destinations.

## Stage 1 acceptance

- Four cardinal stars exist and rotate as one constellation.
- The foreground cardinal is computed from orientation and is the only cardinal label highlighted.
- Opening the foreground cardinal creates an independent four-room cluster.
- The foreground room label changes with cluster rotation.
- Pointer drag and keyboard left/right controls rotate and settle deterministically.
- Enter/Space opens the foreground cardinal; Escape/Return to Orbit restores the constellation.
- Instructions change with constellation, cluster, and room-selected state.
- No carousel, headboard, Mirrorland runtime, H-Earth wiring, or production route mutation is present.

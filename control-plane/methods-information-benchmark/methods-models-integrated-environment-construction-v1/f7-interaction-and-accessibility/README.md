# F7 — Interaction and Accessibility

`F7_INTERACTION_AND_ACCESSIBILITY` is the human-operation layer of `METHODS_MODELS_INTEGRATED_ENVIRONMENT_CONSTRUCTION_v1`.

F7 consumes the exact terminal F6 lineage. It does not create scientific meaning, add a state axis, promote evidence, alter a claim ceiling, create a semantic relation, or authorize visual/spatial construction.

## Governing rule

`INTERACTION_MAY_OPERATE_THE_ENVIRONMENT_BUT_MAY_NOT_ALTER_SCIENTIFIC_STATE_WITHOUT_AN_ALREADY_AUTHORIZED_TRANSITION`.

Interaction events are normalized into registered semantic controls. Pointer, keyboard, touch, and assistive-technology activation of the same control must dispatch the same operation. Focus movement is never activation.

F7 delegates scientific-state-affecting navigation exclusively to the already-frozen F5 route-history-only transition. Explicit depth requests delegate exclusively to F6 and do not mutate canonical scientific state.

Focus target, modality, motion preference, viewport class, and active depth are interaction-session metadata. None is a fourteenth F2 state axis.

Reduced-motion and mobile adaptation may change presentation behavior but may not remove information, functions, qualifiers, adverse findings, or inquiry depth access.

Invalid interactions fail closed and return a recoverable snapshot of the prior authorized context. Silent fallback is prohibited.

## F7 does not authorize

- public Methods/Laws mutation;
- visual construction;
- spatial topology;
- geometry;
- PR #541 mutation;
- F8 construction before F7 terminal PASS.

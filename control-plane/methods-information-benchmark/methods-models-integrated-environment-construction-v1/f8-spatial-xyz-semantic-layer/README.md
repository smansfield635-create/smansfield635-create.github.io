# F8 Spatial / XYZ Semantic Layer

`F8_SPATIAL_XYZ_SEMANTIC_LAYER_v1` is the nonpublic semantic-spatial substrate for the Methods & Models integrated environment.

Authoritative input is restricted to exactly three upstream classes: `CANONICAL_SCIENTIFIC_OBJECTS`, `TYPED_SCIENTIFIC_RELATIONS`, and `GOVERNED_CROSS_ESTATE_PROJECTIONS`.

F8 may express declared meaning spatially. It may not infer scientific meaning from visual design, proximity, geometry, prominence, camera state, gesture, or layout. XYZ values are presentation metadata and never F2 scientific state.

The layer is text-first equivalent, fixed-camera, non-WebGL-dependent, and consumes F7 semantic controls without redefining them. No public page, F9 assembly, claim ceiling, F2 axis, or F3 resolver is modified by this package.

# M1R1 — Method Procedure Field

`M1R1_METHOD_PROCEDURE_FIELD` is the first bounded manifestation revision after the M1 perceptual evaluation failed.

It preserves the exact M1 semantic population: `METHODS`, fifteen source-bound method stages, and the sixteen dependencies derived from `sequence[].requires[]`. It does not add, delete, reinterpret, or infer scientific relations.

The revision changes manifestation only:

- each declared dependency is rendered with source → target direction morphology;
- the active stage emphasizes only its incoming/outgoing declared relations;
- narrow viewports reflow the same bound nodes into a two-column whole-field realization with no horizontal fragmentation;
- custody and orientation labels are made more legible without acquiring semantic authority.

Responsive positions remain nonsemantic. Stage number remains the explicit source-bound order cue. Public Methods files are outside this candidate.

What this build is

Public Talk v1 is intentionally narrow. It uses the verified Qwen2.5 0.5B local runtime for lightweight conversation. It does not claim frontier-model capability or professional authority. Research, Diagnostic, and governed private Execution are separate capability layers and are not exposed by this public chat.

WebLLM 0.2.85 loader code is fetched from a pinned public CDN. Model weights and WebGPU runtime assets are served from this site and inference runs in the browser.

05What would we actually test together?

About 30 minutes. Run that state through the governance layer and see whether it confirms the result, exposes a useful gap, or adds nothing new.
NO SYSTEM INTEGRATION · NO CLIENT-DATA PREPARATION PROJECT · NO COMMITMENT BEYOND THE TEST.
See what the 30-minute test returns

LBS supplies only the facts it already knows from one completed decision or operating cycle. The governance layer determines what is established, negated, unproven or conflicting.

The output is intentionally practical: what the evidence supports → what remains unresolved → what that justifies doing next.

The test succeeds by being informative, not by producing a predetermined positive result. Confirmation, a meaningful gap, or “nothing new” are all valid outcomes.
